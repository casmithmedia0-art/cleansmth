# CLEANSMITH admin setup

The website uses Next.js App Router pages and React components. Public routes are `/`, `/home-cleaning`, `/gardening`, and `/about`; the admin dashboard is `/admin`. The pages include starter content and remain usable if Supabase content is not configured.

1. Create a Supabase project.
2. In the Supabase SQL Editor, run all of `supabase-setup.sql`. If Supabase is already set up, run the updated script again to add missing page, package, and gallery columns, including hero slides and before-and-after media, create the team-members and booking-add-ons tables, relax the obsolete required constraint on the legacy `site_pages.title` column, and refresh access policies. Existing page rows are preserved; default page rows and booking add-ons are inserted only when they do not already exist. Gallery items and packages are assigned to `car-wash`, `home-cleaning`, or `gardening`.
3. In `public/supabase-config.js`, set the project's **Project URL** and **anon/public key**. Never put a `service_role` key in browser code.
4. In Supabase Authentication, create the admin user. Edit that user's **app metadata** to include `{"role":"admin"}`. Do not set this in user-editable metadata. The database policies enforce this role for dashboard data and file uploads.
5. Run `npm run dev` to preview locally. Open `http://localhost:3000/admin` to sign in; all public pages are available without `.html` suffixes.
6. In Vercel, import the repository and leave **Root Directory** set to the repository root (`.`). The Next.js app and `package.json` are at the root of this Git repository; do not use the local computer's folder path as the Vercel root directory. Use the Next.js framework preset and deploy; Vercel detects the npm build configuration automatically.
7. To calculate booking travel fees, enable the Google Maps JavaScript API and Routes API in a Google Cloud project with billing. Create an API key restricted to your website's HTTP referrers and to those APIs. Set `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` in Vercel's Environment Variables, then redeploy; locally, put it in `.env.local` (never commit that file). This browser key is visible to visitors, so keep the referrer and API restrictions enabled. Add localhost and each real Vercel/custom domain to the allowed referrers.

The dashboard's **Services** section manages the service cards published on each website page, including each card's title, description, price label, features, and image URL or upload. Cards can be added, edited, and deleted individually. The same section separately manages optional car-wash booking add-ons, their prices, visibility, and display order. Active add-ons appear in the customer booking form and are included in its estimated total and booking message. The former **Members** dashboard section has been replaced; existing VIP member records remain in the database and are not changed. VIP membership plans remain managed separately. The **About team** section manages public team profiles and photos. **Packages** are assigned to Car Wash, Home Cleaning, or Gardening; only car-wash packages use per-vehicle prices. Gallery uploads accept image and video files up to 100 MB. For a comparison, choose **Before & after** and upload one image for each side. The public galleries only display published entries and show items on the matching service page.

Use **Website pages** to edit each page's hero text, primary hero image (upload an image or paste its URL), additional hero slides, and callout. The page list shows thumbnails of hero images, each with a delete control; uploaded files are removed from storage when no page or service card still uses them. You can also clear the primary image URL and save or remove an additional-slide line and save. Enter additional slides one per line using `Title | Subtitle | Image URL | CTA text | CTA URL`. Use **Services** to add, edit, or delete website service cards with separate fields and image uploads, or to manage car-wash booking add-ons. The About Us page's introduction is the story (separate paragraphs with blank lines), while the section heading and callout fields control the team introduction. Use **Packages** to create and edit service-specific packages; use **About team** to add team members and upload their photos. Image URLs in starter content and gallery samples are examples and can be replaced; fallback gallery samples live in `app/lib/site-content.js`. The homepage displays current Google reviews from `https://cleansmith.revue.us/reviews`; review content is fetched from the public review feed and is not hardcoded in the website. The car-wash booking form collects make, model, year, and vehicle size; package prices continue to use the size categories configured under **Packages**.

The browser-side project URL and anon key are public by design. Access control relies on Supabase Auth and the row-level security policies in the setup SQL.

The booking form calculates Google Maps driving distance from **2 Bank Road, Johannesburg** to the supplied service address. The first 5 km are included; each started kilometre beyond that costs R15 (for example, 5.1 km adds R15). The travel fee is included in the estimate and booking message. The booking form requires a successful route calculation before it can continue.
